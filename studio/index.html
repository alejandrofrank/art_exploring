Inspect the pipeline
  1. Sample: area-average the source into a bounded grid, accounting for alpha.
  2. Adjust: saturation → brightness → contrast → optional seeded grain.
  3. Represent: nearest palette color, ordered/error-diffusion dither, or bitmap characters.
  4. Export: integer nearest-neighbor scaling. No smoothing, server upload or generated detail.

Recipes store all settings and a sample ID or source-image fingerprint. User images are not included: reopen the original file to reproduce them. Input is normalized to 1600 px on its longest edge. PNG output is capped at 4096 px per edge.
